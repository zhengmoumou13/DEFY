# AI 服务配置与排错

## 三类服务

在 **我的 → AI 服务** 中分别进入配置页。每类都需要 HTTPS 地址、该服务的 API Key 和准确模型 ID；仓库不提供密钥或服务额度。

| 类型 | 发送内容 / 用途 | 协议 |
| --- | --- | --- |
| 文字 AI | 计划、对话、任务拆解、复盘所需的输入和上下文 | `chat/completions` |
| 图片分析 | 所选图片、场景、备注和相关训练档案 | 支持 `image_url` 的 `chat/completions` |
| 语音转文字 | 当前录音；转写结果回到输入框 | `audio/transcriptions` |

端点通常填写 `https://provider.example/v1` 这样的基础地址，客户端会拼接功能路径；相关客户端也接受对应的完整端点。请不要重复写成两段 `chat/completions`。地址不允许嵌入用户名、密码、查询参数或片段，不支持明文 HTTP。

## 文字服务示例

项目提供 DeepSeek 和智谱 GLM 快捷填写项。示例表示当前客户端预设，不保证账户必然有模型权限：

| 服务 | 地址 | 预设模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| 智谱标准 API | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.7` |

模型名可修改。使用服务商账户实际可用的模型、接口和额度；文字订阅或编程工具订阅不应直接等同于标准 API 余额。

GLM 的部分型号会返回推理内容，客户端按已知型号适配思考参数与输出预算。只有推理字段、没有正常正文或输出截断的响应，不按正常计划处理。未知新型号需要额外验证，不自动宣称兼容。

## 图片服务的兼容行为

图片设置可以单独保存地址、模型和密钥。当前实现仍保留早期版本的行为：没有已保存的图片密钥时，配置流可能使用文字密钥作为兼容默认值。因此它并非严格的“空密钥即禁用图片服务”。

**使用不同供应商时，明确填写图片服务自己的密钥并测试后保存。** 快捷切换供应商会清空表单密钥，恢复备份时服务地址变化也会清除对应旧密钥。不要依赖文字模型具备视觉能力；服务端必须接受图片输入格式。

## GLM-ASR-2512 语音

进入 **语音转文字 → 智谱 GLM-ASR-2512**：

- 地址：`https://open.bigmodel.cn/api/paas/v4`
- 模型：`glm-asr-2512`
- Key：自行填写该语音服务的标准 API 密钥。

语音配置全部独立，未填写完整时不借用文字或图片密钥。GLM 使用 16 kHz、单声道 PCM WAV 和专用 JSON 请求；通用兼容服务使用 multipart M4A/AAC。录音上限分别为 30 秒与 60 秒。

按住开始、松开转写、移出取消。首次麦克风授权后需要重新按住。识别结果先追加到输入框，检查后再发送；不会自动把录音内容交给文字 AI 回答。当前没有 Android 系统识别入口，也没有用 `glm-4-voice` 代替纯转写。

## 测试连接与保存

1. 填写当前服务的三项配置。
2. 点击“测试连接”，等待或取消请求。
3. 通过后点击“保存服务配置”。测试本身不会保存。
4. 修改地址、Key 或模型后，旧测试结果失效；离开未保存表单有提示。

测试素材：文字使用短消息，图片使用内置色块图，语音使用一秒静音 WAV。语音测试不会启动麦克风。静音请求通过只能说明接口接受该测试，识别质量还需要实际录音验证。测试可能产生费用。

## 常见错误

| 情况 | 检查方向 |
| --- | --- |
| 401 / 403 | 密钥是否属于当前服务、是否完整、权限是否开放 |
| 400 / 404 / 415 / 422 | 基础路径是否正确、模型 ID 与协议是否支持 |
| 429 | 额度、限流和并发请求 |
| GLM 1113 | 标准 API 余额 / 账户权限，不能据此推断所有订阅都可用 |
| 仅返回思考、正文空或截断 | 模型输出预算及已知适配范围，检查具体模型 |
| 网络失败或超时 | HTTPS 证书、设备网络、服务地址和服务可用性 |
| 图片失败、文字成功 | 图片模型是否支持视觉，不能只看文字请求测试 |
| 语音无文字 | 静音、音量、语言、模型或请求格式；检查实际录音 |

提交问题时提供 App / Android 版本、服务商、模型名、错误码和脱敏步骤即可。**不要贴 Key、完整请求头、私人录音或含个人档案的完整日志。**
