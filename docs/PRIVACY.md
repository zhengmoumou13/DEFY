# 数据、隐私与权限

本说明描述当前公开源码行为，不是第三方 AI 服务的隐私承诺。DEFY 没有随仓库提供的账号服务器或第一方云同步。

## 本地保存

Room 保存训练、计划、身体、饮食及其他记录；DataStore 保存偏好与配置。导入附件、动作视频和备份保存在应用相关的文件目录中。使用系统分享或导出后，副本会进入用户选择的目标位置。

API Key 使用 Android Keystore 支持的加密方式后存入配置，导出备份不包含密钥。加密密钥与当前设备 / 安装环境有关，换机或卸载后不能依赖原加密值恢复服务。应用数据库和 `.dwb` 备份本身并没有整体加密，不能把密钥加密理解成所有数据都加密。

## 哪些操作会联网

| 操作 | 可能发送给配置的服务 |
| --- | --- |
| 生成计划、聊天、复盘、其他文字 AI | 当前输入、功能提示词，以及该功能需要的档案、历史摘要或计划上下文 |
| AI 有球计划 | 档案、本次条件和近期有球训练汇总 |
| 照片分析 | 主动选择的照片（处理后）、备注、场景与相关档案 |
| 语音转写 | 当前录音，识别结果回填本机输入框 |
| 测试连接 | 内置短消息、色块图片或静音 WAV |
| 打开项目 / 数据来源链接 | 系统浏览器向对应网站发起访问 |

服务地址由用户配置。数据保留、模型训练使用、地域和删除规则取决于服务商；应用无法替对方承诺“不保留”或“不训练”。照片上传前会处理方向并移除 EXIF 元数据，但图片画面本身仍可能包含隐私。

仓库未集成广告或统计遥测 SDK。离线动作库、模板记录和食物换算本身无需调用 AI。

## 麦克风与临时媒体

语音输入要求主动开始录音；首次授权后需重新按住。松开提交转写，移出按钮或退到后台取消。成功或关闭流程后清理临时录音，失败时可能保留当前录音用于重试。操作系统、进程异常退出和文件生命周期并不等同于安全擦除。

图片由用户选择或通过系统相机获取。动作演示视频需自行拥有版权或复用许可；导入本身不会把视频发布给其他用户。

## 权限

| 权限 / 系统能力 | 用途 |
| --- | --- |
| INTERNET | 用户配置的 AI 服务和网络请求 |
| RECORD_AUDIO | 主动发起的语音录音 |
| POST_NOTIFICATIONS | 提醒 / 计时等通知，视 Android 版本请求授权 |
| SCHEDULE_EXACT_ALARM | 日程等精确提醒，具体受系统授权和省电策略影响 |
| 系统相机、文件选择、分享 | 使用系统交互导入 / 导出内容，不代表扫描全部媒体库 |

Android 系统备份在 Manifest 中关闭，应用另有用户可见的 `.dwb` 导出与本机自动备份。

## 备份与删除

- `.dwb` 是快照与附件的 ZIP，可包含训练、身体、饮食、笔记、文件和自有视频。
- 导出文件不含 API Key，但包含非密钥服务配置和个人记录；**不加密**。
- 应用退到后台会尝试自动备份，保留最近 5 份；导入 / 恢复前建议先导出当前数据。
- 卸载或清除应用数据会删除相应的私有记录；已经导出或分享的副本需要在目标位置另行处理。
- 解除动作视频关联并不一定删除资料库里的原文件，需要在文件资料中自行清理。

## 公开反馈

Issue、PR、附件和提交记录可能被所有人看到。请删除密钥、设备标识、账号、真实健康档案和可识别个人的照片 / 音频。不要上传 `.dwb`、数据库或手机完整日志。安全问题请按 [SECURITY.md](../SECURITY.md) 私下报告。
