# 测试与回归

## 自动化入口

```bash
python3 scripts/check_public_files.py
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

首次开源基线有 **91 项 JVM 测试**，测试不依赖个人 AI 密钥，也不调用真实服务。后续以 Gradle 实际报告为准，不用 README 的数字替代测试结果。

覆盖内容包括：

- 训练 / 饮食任务解析与展示，说明不计为任务、可选餐次、Markdown 外层包装、旧键兼容。
- 食品重量缩放、营养目标反推、替换差异、汇总、非法数值及包装标签单位。
- 动作库和模板引用、原创示意匹配与训练数据处理。
- GLM 参数 / 响应兼容、连接测试、语音请求与独立配置。
- 档案校验等纯逻辑。

计划样例在 `app/src/test/resources/plans/`。请使用合成或脱敏文本；不要把真实 API 响应中的个人资料直接作为测试资源。

## 已知缺口

- 没有完整的端到端 UI 自动化套件。
- Room 迁移和备份 / 附件恢复仍需更系统的测试覆盖。
- Lint 首次开源检查有 114 个 warning、12 个 hint，无 error；警告数量可能随工具版本变化。
- 不能以单次连接测试推断模型权限、识别质量或服务商未来兼容性。

## 建议回归清单

1. 安装与升级：签名、版本号、已有数据库和配置。
2. 计划：生成失败不覆盖、日期切换、原文、折叠区、任务预览。
3. 执行：勾选与说明分离、编辑后的键、逐组记录、恢复未结束场次。
4. 表单：校验、键盘遮挡、未保存返回、取消 / 重试。
5. 媒体：首次授权、移出取消、后台取消、断网重试、临时文件。
6. 营养：可食部和生熟状态、单位、非法值、单营养等量含义。
7. 外观：浅 / 深色、窄屏、大字体、主题图标和可读对比度。
8. 数据：先导出再恢复、旧快照兼容、附件与密钥排除。

完整设备日志与私人测试产物不随仓库发布。PR 中只提供脱敏复现步骤和与改动有关的验证证据。
